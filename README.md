# V-Code SaaS Landing Page

A fully responsive, animated, and modern **SaaS landing page** built as part of an interview assignment. The UI design was initially scaffolded using **Vercel v0 (v0.app)** and then customized manually using **Next.js & Tailwind CSS**.
